IZA'S LITTLE GARDEN

Files:
- index.html
- style.css
- script.js

How to open:
1. Keep all three files in the same folder.
2. Double-click index.html, or open it with VS Code Live Server.
3. Click "Let's go →".
4. Click "How's your mood right now?".
5. Choose a mood.

Everything is built with plain HTML, CSS and JavaScript.
No libraries or internet connection are required.
